# EduLyra Run Guide

1. Open a terminal inside the `EduLyra2` folder.
2. Run `npm install`.
3. Run `npm run build`.
4. Run `npm run dev`.
5. Open the Vite URL shown in the terminal.

## Demo accounts
- Student: `student@demo.com`
- Faculty: `faculty@demo.com`
- Industry: `industry@demo.com`
- Institution: `admin@demo.com`
- Demo password for all: `EduLyra@2026!Demo`

## Industry test flow
1. Log in as Industry.
2. Post an Opportunity.
3. Post a Challenge.
4. Post Training.
5. Post a Workshop.
6. Open Training & Certification.
7. Select a Student or Faculty recipient and issue a certification.
8. Log in as that recipient and verify the certification appears in the existing certification/profile area.
