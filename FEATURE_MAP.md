# EduLyra Feature Map — Strict Student UX Upgrade

| Existing feature | Improvement | Connected behavior |
|---|---|---|
| Student sidebar | Removed standalone Learning navigation | Learning remains contextual through Career Intelligence, Roadmap and Skill Gaps |
| Recommended Courses | Context-aware Open Learning | Opens mapped subject/course instead of a generic route |
| Skill Gap Intelligence | Context-aware Learn this skill | Skill is mapped to a valid learning subject |
| Smart Learning | URL-driven subject selection | Course/topic/video remain aligned |
| 90-Day Roadmap | Persisted completion state | Completion survives navigation and updates profile roadmap state |
| Career Intelligence | Contextual Start Learning | Opens the highest-priority mapped learning subject |
| Notifications | Contextual Learning destination | Learning notification opens the relevant subject |
| Global visual system | Violet + Cyan + Midnight + White | Consistent premium AI-career visual identity |

## Connected loop

Career goal → Skill Demand → Skill Gap → contextual learning → course/topic/video → quick check → practice → skill update → Career Intelligence/readiness → roadmap → opportunities.
