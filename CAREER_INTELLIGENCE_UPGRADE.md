# EduLyra — Career Intelligence Upgrade

This build keeps the existing EduLyra stakeholder workflows and adds a new **Career Intelligence Hub** for students.

### Added
1. AI Career Twin
2. What-If Career Simulator
3. Skill Demand Radar
4. Career Readiness Score
5. AI Personalized Skill Roadmap
6. Evidence-Based Verified Skill Passport
7. Industry–Academia Project Marketplace

### Where to open it
After starting the Vite app, log in as a Student and open:
`/student/intelligence`

The Student Dashboard also contains a new **Career Intelligence Hub** card linking to the page.

### Run
```bash
npm install
npm run dev
```
